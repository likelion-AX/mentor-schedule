# 구글 캘린더 → 앱 (개인 약속 가져오기) — 설치 가이드 (운영팀용)

멘토가 구글 캘린더에 적어둔 **개인 약속을 자동으로 "불가 시간"으로 가져와서**, 운영팀 배정 시 충돌이 자동으로 잡히게 하는 기능입니다.

## 🔒 보안 요약 (먼저 안심하시라고)
- 구글 약속의 **제목·내용·장소는 함수가 받기 전에 통째로 삭제** → 우리 서버도 안 보고, DB에도 저장 안 됨. **시간만** 저장.
- 운영팀 화면엔 **"🔒 개인 일정 + 시간"만** 보이고 내용은 안 보임. 다른 멘토는 원래 개인일정 자체를 못 봄.
- 멘토의 구글 **비공개 주소**는 본인만 접근(전용 테이블 RLS). **운영팀도 그 주소는 못 읽음.**

---

## 작동에 꼭 필요한 것 (1~2단계) — 이것만 하면 "지금 동기화" 버튼으로 바로 됨

### 1단계 — SQL 실행
- SQL Editor → **+ New query** → **`supabase/calendar-import.sql`** 전부 붙여넣고 **Run**.
- (표 `mentor_calendar_links` + `mentor_blocks.source` 컬럼만 추가. 기존 데이터 안 건드림. 재실행 안전.)

### 2단계 — 엣지 함수 배포 `sync-google-calendars`
1. Edge Functions → **Deploy a new function → Via Editor**
2. 이름: **`sync-google-calendars`**
3. 코드 다 지우고 → **`supabase/functions/sync-google-calendars/index.ts`** 전부 붙여넣기
4. **★ "Verify JWT" 끄기(OFF) ★** (calendar-feed 때와 동일. Settings 탭에서 OFF 후 Save)
5. **Deploy**

> 만약 배포가 `npm:ical.js` 관련 오류로 실패하면, 코드 맨 위 줄을
> `import ICAL from "npm:ical.js@1.5.0";` →
> `import ICAL from "https://esm.sh/ical.js@1.5.0";` 로 바꿔서 다시 Deploy 하세요.

✅ 여기까지 하면: 멘토 화면 "개인 일정 등록" 카드 아래 **📥 구글 캘린더에서 가져오기**에서 비공개 주소를 연결하고 **[지금 동기화]** 를 누르면 바로 들어옵니다.

---

## 자동으로 주기 갱신 (3단계) — 선택, 하지만 추천

이걸 안 하면 멘토가 매번 **[지금 동기화]** 를 눌러야 해요. 자동으로 알아서 갱신되게 하려면:

### 3-1. 비밀값(SYNC_SECRET) 만들기
- Edge Functions → **Secrets** → **Add new secret**
- Name: `SYNC_SECRET`, Value: 아무 긴 무작위 문자열(예: 영문+숫자 30자 이상). 어딘가 메모해 두기.

### 3-2. cron 등록
- SQL Editor → **+ New query** → **`supabase/calendar-import-cron.sql`** 붙여넣기
- 파일 안 `PUT_YOUR_SYNC_SECRET_HERE` 를 **3-1에서 만든 값과 똑같이** 바꾸기
- **Run** → 3시간마다 자동 동기화됨.

> Supabase 대시보드에 **Integrations → Cron** 메뉴가 있으면 거기서 클릭으로도 등록 가능(같은 함수·헤더 사용). SQL이 편하면 위 방법으로.

## 테스트
1. 멘토 화면(내 일정) → "개인 일정 등록" 카드 아래 **📥 구글 캘린더에서 가져오기**
2. **구글 "비공개 주소" 찾는 법** 펼쳐서 안내대로 주소 복사 → 칸에 붙여넣고 **연결**
3. 자동으로 "가져오는 중…" → 잠시 뒤 **N건** 표시
4. 캘린더에 구글 개인 약속이 **🔒 개인 일정(구글)** 으로 회색 표시되면 성공 ✅
5. 운영팀 화면에서 그 멘토 보면, 그 시간에 **개인일정 충돌**로 잡힘(내용은 안 보이고 시간만)

문제 시:
- "no link" → 1단계 SQL 또는 연결 안 됨
- "invalid token" → 로그인 풀림(새로고침 후 재시도)
- 함수 로그(Edge Functions → 해당 함수 → Logs)에서 error 메시지 확인
