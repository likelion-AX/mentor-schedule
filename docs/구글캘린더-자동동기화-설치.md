# 구글 캘린더 자동 동기화 — 설치 가이드 (운영팀용)

멘토가 본인 일정(배정 교육 + 개인 일정)을 **구글 캘린더에 한 번 등록하면 자동으로 갱신**되게 하는 기능입니다.
설치는 **딱 2단계**(SQL 실행 → 엣지 함수 배포)예요. 순서대로만 하면 됩니다.

> 동작 원리(참고): 멘토마다 비밀 주소(URL)가 하나 생기고, 구글 캘린더가 그 주소를 주기적으로 읽어갑니다.
> 주소 안의 **토큰**이 비밀번호 역할을 해서, 그 사람 일정만 나옵니다. (남이 토큰을 모르면 못 봄)

---

## 1단계 — SQL 실행 (구독 토큰 준비)

1. Supabase 접속 → 왼쪽 메뉴 **SQL Editor**.
2. 오른쪽 위 **+ New query** (새 쿼리) 클릭. (기존 쿼리 위에 덮어쓰지 말고 **새 탭**에서)
3. 프로젝트 폴더의 **`supabase/calendar-feed.sql`** 파일 내용을 **전부 복사**해 붙여넣기.
4. 오른쪽 아래 **Run** (또는 Ctrl+Enter).
5. 아래에 **Success. No rows returned** 비슷하게 뜨면 성공.

> 이 SQL은 `calendar_feeds`라는 **새 표**와 함수 2개(토큰 발급/재발급)만 추가합니다.
> 기존 표를 건드리거나 지우지 않아요. 여러 번 실행해도 안전합니다.

---

## 2단계 — 엣지 함수 배포 (`calendar-feed`)

멘토 주소를 누르면 일정을 `.ics`(캘린더 파일)로 만들어주는 작은 프로그램입니다.

1. Supabase → 왼쪽 메뉴 **Edge Functions**.
2. **Deploy a new function** → **Via Editor**(에디터로 작성) 선택.
3. 함수 이름(Name)에 정확히 `calendar-feed` 입력.
4. 코드 칸의 내용을 **전부 지우고**, 프로젝트의 **`supabase/functions/calendar-feed/index.ts`** 내용을 **전부 복사**해 붙여넣기.
5. **★중요★ JWT 검증 끄기** — 이 함수는 구글이 *로그인 없이* 불러가야 하므로 인증을 꺼야 합니다.
   - 배포 화면에 **"Verify JWT" / "Enforce JWT verification"** 같은 스위치가 있으면 **끄기(OFF)**.
   - 배포 화면에 없으면 일단 배포 후, 함수 상세 → **Settings(설정)** 에서 **Verify JWT** 를 찾아 **OFF**.
6. **Deploy** 클릭.

> 이 함수는 별도 비밀키 설정이 필요 없어요. (Supabase가 내부적으로 주는 키만 씁니다.)

### 잘 됐는지 확인
- 멘토 화면(내 일정)에 새로 생긴 **"📅 구글 캘린더 자동 동기화"** 카드에서 **내 구독 주소**가 보이면 1단계 성공.
- 그 주소를 복사해 브라우저 새 탭에 붙여 열었을 때, `BEGIN:VCALENDAR ...` 같은 텍스트가 보이거나 파일이 받아지면 2단계 성공.
- 만약 `401`, `Invalid JWT`, "Missing authorization" 류가 보이면 → **JWT 검증이 아직 켜져 있는 것**. 2-5단계의 OFF를 다시 확인.

---

## 멘토가 쓰는 법 (안내용)

1. 멘토 화면 **"📅 구글 캘린더 자동 동기화"** 카드 → **주소 복사**.
2. PC에서 **구글 캘린더**(calendar.google.com) 열기.
3. 왼쪽 **다른 캘린더 +** → **URL로 추가**.
4. 복사한 주소 붙여넣고 **캘린더 추가**.
5. 끝. 이후 배정·개인일정이 바뀌면 구글이 자동으로 가져옵니다.

> **갱신 속도**: 구글은 구독 캘린더를 보통 **몇 시간~하루**에 한 번 갱신합니다(구글 정책, 우리가 못 바꿈).
> 방금 바뀐 걸 **즉시** 보고 싶으면 배정 카드의 **⬇.ics** 버튼으로 그때그때 받는 방법을 함께 쓰면 됩니다.

---

## 보안 / 주의

- 구독 주소는 **본인만 아는 비밀**입니다. 주소를 받은 사람은 그 멘토 일정을 볼 수 있으니 공유 금지.
- 주소가 새어나갔으면 멘토가 카드의 **주소 재발급**을 누르면 됩니다. (옛 주소는 그 즉시 무효 → 구글에서 다시 URL로 추가)
- 개인 일정(🔒)도 이 구독에 포함됩니다. 본인 캘린더로만 가니 멘토끼리는 여전히 비공개입니다.
